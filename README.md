# T1-Grupo06-Caso2

## Descripción

Resolución del caso 2 de la actividad calificada T1 para el curso SOLUCIONES WEB Y APLI. DIST. Desarrollado por el Grupo 06.

## Dependencias utilizadas

- Angular
- Bootstrap

## Instalación de dependencias

```bash
npm install
```

## Ejecución de la aplicación

```bash
ng serve -o
```

La aplicación estará disponible en:

http://localhost:4200/
